# 放心用 · FoodGuard

> 扫一扫食品条形码，看懂配料表，给出安全等级。
> **本地自用离线版**：无后端、无云端 OCR、不上传任何数据、不上架应用商店。

---

## 一句话

**「放心用」** 是一款完全离线的食品安全助手：对准包装上的条形码，或对配料表拍张照（也可手输），
App 在**手机本地**解析配料表、识别食品添加剂、比对 GB 2760 使用规定、评估营养成分，
给出 **A / B / B- / C / D** 五级安全评级与逐项解释。

对标产品：剂安安（深圳市剂康科技，已不可用）。

## 项目定位（已锁定）

| 项 | 决定 |
|:---|:---|
| App 正式名 | **放心用** |
| 工程代号 | `FoodGuard`（内部代码命名保持稳定） |
| Android 包名 | `com.aeromantic.fangxinyong` |
| 后端 | **不接**。无服务端，纯端上 |
| 云端 OCR | **不用**。端上 ML Kit 中文识别 + 手动输入兜底 |
| 分发方式 | **GitHub Releases 发布**，自签 APK 自用 |
| 适用范围 | **所有可食用食品**（含饮料、调味品、保健食品）；**日化/用品不在范围内** |
| 网络 | **可联网自用**：条码 → Open Food Facts / 第三方接口查商品信息（**默认关闭**，需在设置页手动开启）；不开启则全程零网络请求 |
| 数据与隐私 | 条码、配料表、照片**永不上传**；开启联网时仅发出**纯条码号**检索品名 |
